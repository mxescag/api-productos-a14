Operaciones y resolución de problemas

Cómo iniciar la API

  1. Sitúate dónde se encuentre package.json.
  2. Abre un terminal aquí y ejecuta:
npm start

Cómo detener la API

En el terminal donde está corriendo Node, en tu teclado, pulsa ctrl + C. Esto detendrá la API, devolviéndote al prompt del terminal.

Incidencias

Problema Comprobacion Posible solucion
npm no existe npm --version Instalar Node.js/npm
Faltan dependencias Revisar error al iniciar Ejecutar npm install
